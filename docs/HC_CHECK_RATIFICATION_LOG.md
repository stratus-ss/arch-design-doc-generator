# HC Check Rationale Ratification Log

_Created: 2026-08-10_

## Purpose

This log tracks ratification of every `WARNING` and `FAIL` condition documented in
`docs/HC_CHECK_RATIONALE.md`.

Ratification means:
- the cited official documentation URL is reachable, and
- the page content actually supports the threshold or condition claimed by the row.

When a rationale-row citation or threshold is wrong, the correction is applied
directly to `docs/HC_CHECK_RATIONALE.md` and recorded here for traceability.

## Method

1. Process checks in document order (`7.1` -> `7.9`).
2. Skip rows that are purely informational or always-pass/always-skipped and mark
   them `OUT-OF-SCOPE`.
3. Use the matching KB TOML entry as the first citation candidate when available.
4. Fetch the citation and verify the page text supports the exact claim.
5. If the citation is stale, generic, or unsupported, search for a better official
   source and correct the rationale doc when justified.
6. If no official source exists after genuine research, confirm the row as
   engineering judgment instead of pretending it is doc-backed.
7. Never re-do completed work; this file is the resumability checkpoint.

## Status Legend

| Status | Meaning |
|--------|---------|
| `✅ VERIFIED` | Citation is live and the fetched page supports the claimed threshold or condition |
| `🔧 CORRECTED` | The rationale doc was corrected because the citation or threshold was wrong/stale/unsupported |
| `⚠️ ENGINEERING-JUDGMENT-CONFIRMED` | No official source pins the exact threshold; the row is retained as engineering judgment |
| `❌ UNRESOLVED-BLOCKED` | Could not complete verification because of blocking access or unresolved source ambiguity |
| `⏭️ OUT-OF-SCOPE` | Informational-only, always-pass, or always-skipped row that does not require ratification |
